# WallHub v2.0.3

## 中文更新

### 新功能

- 个人 Workshop 页面新增 Steam 原生时间排序：订阅日期、依字母顺序、更新日期和创建日期，支持个人订阅、我的收藏、已投票、好友收藏、好友创建和关注者创建等筛选。
- SteamKit 和 Steam Community 查询现在会直接使用所选的 Steam 排序方式，创建日期等排序结果与 Steam Workshop 页面保持一致。

### 优化

- 更新 Windows 内置 SteamKit 运行时，使个人 Workshop 排序参数在便携版和安装版中保持一致，并移除不准确的本地二次排序路径。
- 刷新 WallHub Logo、favicon 和 README 技术栈徽章，改善应用识别度和项目文档可读性。

### 修复

- 修复 SteamKit 读取已有账户设置时未共享读取句柄，导致并发登录或查询可能遇到文件占用冲突的问题。

## English Release Notes

### Features

- Added Steam-native time sorting to personal Workshop pages: subscription date, alphabetical order, last updated, and creation order. The options are available for subscriptions, favorites, voted items, friends' favorites, friends' creations, and followed authors' creations.
- SteamKit and Steam Community queries now use the selected Steam sorting method directly, keeping results such as creation order consistent with the Steam Workshop page.

### Improvements

- Updated the bundled Windows SteamKit runtimes so personal Workshop sorting stays consistent in portable and installed builds, while removing inaccurate local resorting paths.
- Refreshed the WallHub logo, favicon, and README technology badges for clearer product identity and project documentation.

### Fixes

- Fixed SteamKit account settings reads that did not share the read handle, which could cause file-lock conflicts during concurrent sign-in or query operations.
